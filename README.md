# CDI-Software-Developer-Intern
Order-to-Audit ERP for small food manufacturers (NIT Trichy task). Connects field sales, recipe-based production (BOM), immutable double-entry stock ledgers, and auditor reports into one unified loop. Features role-based access, CGST/SGST/IGST tax invoicing, FIFO costing with overheads, and planned vs actual variance tracking with zero float drift.
